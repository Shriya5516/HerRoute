# 🌸 HerRoute – Solo Travel Planner for Girls

HerRoute is a frontend web application designed to help solo female travelers explore safe destinations, plan trips, and access safety resources.

---

## ✨ Features

- 🔐 Login & Signup UI  
- 🏠 Home Dashboard  
- 🌍 Explore Safe Destinations  
- 📍 Destination Details Page  
- 🧭 Itinerary Planning  
- 🚨 Emergency Contacts & Safety Tips  
- 👤 Profile Section  

---

## 🎯 Objective

To provide a simple and safe platform for solo female travelers to plan their journeys with confidence.

---
